# BeamWise AI

Interactive educational beam-analysis app built with Streamlit.

## Features
- Simply supported and cantilever beams
- Point loads and uniformly distributed loads (UDLs)
- Support reactions, SFD, BMD, maximum shear/moment
- Step-by-step equilibrium summary and CSV export

## Deploy
Upload `app.py`, `requirements.txt`, and `README.md` to a GitHub repository. Then create an app at https://share.streamlit.io/ and select `app.py` as the main file.

## Limitations
This is an educational first version for static vertical loads. Verify calculations and sign conventions against known textbook examples. It does not cover inclined loads, applied couples, internal hinges, indeterminate beams, or deflection yet. Not intended as a substitute for professional engineering review.
